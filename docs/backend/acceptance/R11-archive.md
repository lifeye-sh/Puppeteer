# R11 第一阶段：加密归档基础层

此文件为历史阶段记录；后续工作现已完成开发与内网验收，当前状态及完整证据见 [R11 验收记录](R11.md)。以下保留当时的实施边界。

2026-10-30，开发中。本阶段不代表 R11 完成，尚未开放前端备份/恢复能力，也未更改运行中的数据库或部署新服务。

已实现 backup 模块：age X25519 + tar，manifest 第一项且最多 1 MiB，明确格式、schema、PG18、范围及包含/排除项；按条目流式计算 SHA256，拒绝越界路径、重复条目、条目错序、大小不符、缺少数据库或密钥包、未来 schema 和超限归档。读取到加密流末尾，验证最终认证块；不提取归档、不执行 SQL。

离线 CLI：`nt backup keygen --output <新私钥文件>`，只打印接收者公钥，私钥使用独占创建且不覆盖既有文件；`nt backup inspect --archive <归档> --identity-file <离线私钥文件>`，完整校验通过后输出清单。生产私钥保管和 Windows ACL 尚需在部署阶段落实。

测试：加密往返、错密钥、截断认证块、追加密文、未来 schema、源文件变化、路径穿越和重复条目拦截通过；backup 与 nt 定向测试及 go vet 通过。日志：backend/.local/r11-archive-tests.log。

后续：实际一致性备份和 CA/KEK 导出、维护协调器、备份任务 API/页面、隔离数据库恢复与秘密核验、旧登录/任务吊销、切换与离线日志、远端复制/保留、pgBackRest 与 RPO/RTO 演练。backup.restore 能力保持未开放。
