## 前端验收步骤

1. 管理员打开首页，核对 R03、schema 3、能力版本 3。进入“凭据”新建密码凭据，或选择 SSH 私钥：可粘贴带 Passphrase 的 PEM，也可在后端生成 Ed25519 密钥。列表只显示掩码；公钥可复制，生成不等于已安装到目标机器。
2. 进入“资产”，新建或编辑 SSH 资产，指定 IP/域名、端口、共享凭据、分组、标签与启用状态。保存、刷新检查持久化。分组支持父子关系；环、非空分组删除和旧版本编辑会被拒绝。
3. 在“资源授权”把 A 授给 operator。使用独立浏览器或无痕窗口登录 operator，打开“我的资产”，应只有 A。搜索 B 无结果；没有资产管理菜单也能使用个人门户。
4. 将分组授权给用户或其直接所属部门，确认其子分组资产动态出现。移动资产/子分组、禁用资产、设置授权到期或撤销授权后，后续 API 即按新范围过滤，页面通常 5 秒内更新。部门只匹配直接成员，本轮不继承父部门成员。
5. “脱敏导出”下载 JSON。以导出为模板，修改名称和别名，保留当前实例有效的分组/凭据 ID 后导入。每批最多 100 行，每行单独成功或失败；故意将一行端口设为 0，检查逐行错误。导入不会覆盖已有资产。跨实例需映射引用 ID。
6. 在凭据页点“引用”核对资产名称；尝试删除共享凭据，应提示仍被引用。编辑时不勾选“更新秘密”保留原秘密；勾选后产生新版本并影响所有引用资产。
7. 查看秘密需管理员自身密码和已绑定 TOTP 的新动态口令，未绑定时拒绝；恢复码不能用于此操作。关闭弹窗清除显示。首页审计包含 credential.revealed，秘密本身不写入日志。
8. “TCP 检查”只测试保存的启用资产。对自己的真实主机检查可达/不可达，结果明确标注 TCP；本轮不启动 SSH 会话。

角色新增 asset.read、credential.read、grant.read 三项查看权限。管理写操作仍为系统管理员专属；资源授权是独立的用户/部门到资产/分组关系，不把菜单查看权限等同于连接授权。
