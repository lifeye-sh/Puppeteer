# 后台导航分层

更新日期：2026-11-14。导航采用两层结构：数据概览独立展示，其余页面按工作场景归入八个分组。

| 一级入口 | 二级页面 |
| --- | --- |
| 数据概览 | 仪表盘 |
| 工作台 | 我的资产、AI 助手、我的数据库、我的 Web 资产、我的命令片段、我的申请、我的 SQL 工单、存储空间、通知偏好 |
| 资源管理 | 主机资产、数据库资产、Web 资产、授权凭据、证书管理 |
| 接入管理 | Agent 网关、SSH 跳板、网关组、网络代理、Web 接入设置、应用与原生接入 |
| 访问控制 | 资源授权、访问策略、动作策略、命令过滤、IP 集合、访问审批、SQL 工单审批 |
| 会话审计 | 在线会话、访问记录、访问统计、命令记录、文件审计、数据库 SQL 审计 |
| 身份认证 | 用户管理、部门管理、角色权限、登录与身份源、登录锁定 |
| 系统运维 | 任务调度、系统命令片段、凭据轮换、监控与告警、链路诊断、备份与恢复 |
| 平台配置 | 配置总览、服务部署、外部依赖、业务策略、通知渠道与规则、状态与发布 |

## 入口边界

- 工作台面向个人使用；资源管理面向资产维护；接入管理集中管理网络通道及应用接入。
- 访问控制集中授权、策略与审批；会话审计集中会话和操作记录。
- 身份认证管理账号、组织和登录方式；系统运维管理任务、监控和备份；平台配置按部署、依赖和策略分组。
- 个人信息、个人访问凭据保留在右上角用户菜单，终端保留独立工作区。
- `/notification-preferences` 只展示个人通知偏好；管理员的 `/setting` 管理通知渠道等配置。普通用户访问旧 `/setting` 地址时跳转个人通知偏好。
- `/identity-settings` 集中登录策略、验证与恢复、OIDC / 企业微信及 LDAP 配置，取消原设置页中的多层嵌套。
- 备份与恢复统一使用 `/system-event`，不再嵌入通知或身份设置页。

## 导航行为与维护

- 展开侧栏时只展开当前一个分组；直接访问页面或浏览器前进、后退时跟随所属分组。侧栏收起或窄屏进入页面时不自动弹出浮层。
- 面包屑使用“首页 / 分组 / 页面”，菜单高亮与面包屑共用导航定义。
- 页面通过客户端路由切换，保持管理框架，不触发整页刷新。
- 保留原路由。数据库及 Web 资源授权旧入口归属“资源授权”。
- 按已有账号权限与后端能力过滤菜单，隐藏空分组；实际授权仍由页面路由和后端执行。
- 集中配置文件：`src/pages/backend/backend-navigation.ts`。新增页面时在对应分组配置路径、名称、权限和能力，同时维护 `src/App.tsx` 的路由保护。

验证命令：`node --experimental-strip-types --test tests/backend-navigation.test.mjs tests/platform-settings-model.test.mjs`、`node node_modules/typescript/bin/tsc --build`、`npm run release:frontend`。

## 平台配置路由

| 路径 | 内容 |
| --- | --- |
| `/system-status` | 配置总览与四维状态解释 |
| `/deployment-settings` | 代理部署、图形组件、共享盘、MP4 渲染、Agent 仓库、WAL / PITR、入口限制、监听与证书 |
| `/integration-settings` | 外部依赖、默认模型、原生 DML 与受控转发 |
| `/policy-settings` | 登录、会话、AI、录屏及数据等业务策略 |
| `/configuration-status` | 配置发布、许可及运行能力 |
| `/setting` | 通知渠道与规则（原路径保持） |

旧 `/system-status?section=...` 跳转到新路径并保留查询参数；默认模型配置从 AI 策略拆出，原生 DML 从数据库查询参数拆出。已有身份源和模型列表中的“平台配置”链接直接进入对应新页面。

部署页可供拥有 `settings.read` 且支持配置版本的账号查看监听配置；实际“代理部署”仍限管理员且要求 `identity.manage`。只有 `identity.manage` 的非管理员不会因此获得部署入口。业务策略没有配置版本能力时仍可查看其有权读取的日志保留设置。无可用配置项时显示权限或能力不足。

配置总览保留四维状态说明；支持 `system.settings.operations` 的服务端在“状态与发布”提供“预检与服务”页签，展示实际证据、节点确认和持久任务。未适配检测的功能显示未检测。接口及边界见 [统一配置状态](../CONFIGURATION-STATUS.md)，后续计划见 [配置分类与自动化开发计划](../CONFIGURATION-AUTOMATION-ROADMAP.md)。

本次验证：导航、配置分类、配置字段隔离与 HTTP 响应回归共 21 项通过；完整 TypeScript 构建和生产打包通过。浏览器使用 API 夹具验证分组跳转、旧链接参数保留、模型与策略拆分、只读及委派账号权限、运行状态路由和窄屏布局；该交互验证不代表外部服务已就绪。

图形组件页签为 `/deployment-settings?section=components`，仅管理员且具备 `identity.manage` 可操作。表单不显示宿主端口，独立展示部署配置、实时组件状态和连接中断说明；旧执行器不支持时禁止提交。

RDP 共享盘单独使用 `/deployment-settings?section=drive`，与图形服务的开关及表单隔离。操作仍限管理员且要求 `identity.manage`；用户文件页只说明配置是否启用，不将开关当成挂载证明。

MP4 渲染器使用 `/deployment-settings?section=mp4`，无宿主端口表单。启停前说明连接中断和队列暂停保留策略；录屏导出页在停用时提示任务保留，已完成缓存仍按原权限下载。

监听与证书页 `/deployment-settings?section=listeners` 包含原生 RDP 能力面板。只读账号可查看，管理员可提交持久化能力预检；不增加公网 RDP 开放开关。

P2 专项页签为 `/deployment-settings?section=agent-repository`、`?section=wal`、`?section=web-access`；顺序位于 P0/P1 部署项之后。均要求管理员及 `identity.manage`，显示预检/部署/恢复进度和四维状态。

外部依赖页与通知、身份源、模型、备份目标、ACME、Agent/跳板/网关/代理列表详情复用依赖面板。原生客户端依赖在 OIDC 服务端配置内单独展示，预检不替代用户与资产授权。
