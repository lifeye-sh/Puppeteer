## r06.1-preview 控制通道

- 客户端使用 coder/websocket v1.8.14 NetConn + hashicorp/yamux v0.1.2，协议 nt-agent.v1，首流为 hello/hello_ack 控制流；未知消息、错误 epoch 和额外流关闭连接。目前只开放 heartbeat capability。
- 每次连接在数据库递增 epoch；新连接替换旧连接。每 2 秒复核 epoch 与吊销状态，数据库复核失败关闭连接；同进程管理员撤销提交后立即取消通道。进程重启不依据旧数据库心跳伪装在线。
- 心跳间隔 30 秒，90 秒无消息关闭；握手 10 秒，写停滞 15 秒。连接最长 4 小时后客户端重连。客户端断线指数退避并加抖动，不恢复任何业务流。
- 默认 HTTPS/WSS 与证书验证，禁止跟随重定向；仅显式 allow-insecure-development 开启 HTTP/WS。Agent 注册令牌从 0600 文件读取，设备配置独占创建、0600 写入并 fsync；不从命令行读取令牌，不在日志打印凭据。
- Linux amd64 下载接口需要 identity.manage，程序仅以前台普通用户进程运行。Windows 预览明确拒绝运行，待服务账户 ACL 安装方案实现。
- 集成测试使用真实 WebSocket/yamux 客户端，验证首次连接、心跳持久化、新 epoch 关闭旧连接、断线重连、撤销关闭及拒绝再连；Go 全量、go vet、TypeScript 与前端构建通过。
- 升级前备份 backend/.local/r06-registration-before-channel.dump，迁移 008_agent_channel.sql，schemaVersion=8。整轮 R06 仍 in_progress，尚未进入 SSH 网关验收。

## r06.2-preview 受限 Agent 拨号

- 资产新增可选 agentId，管理员在“连接路径”选择 Agent；为空时直连。目标地址在 Agent 网络内解析；离线、旧客户端或目标拒绝均返回失败，绝不回退直连。主机密钥探测与正式 SSH 使用同一选择的路径。
- 只有声明 dial.v1 的 Agent 可接收数据流。服务端重新检查设备 epoch、网站身份、资产授权、资产/凭据/主机信任版本和会话有效期；每 3 秒发送最长 10 秒的目标绑定租约。Agent 使用接收时的单调时钟截止值，过期取消 TCP 与 stream；心跳不续期业务租约。双方时钟需要同步，异常过长/过期租约拒绝。
- Agent 校验端口和所有 DNS 候选 IP，然后连接固定 IP；拒绝未指定、多播、链路本地地址（包括 169.254.169.254），回环只在精确 /32 或 /128 授权时允许。不提供任意 SOCKS 出口。
- 每个 Agent 最多 64 个拨号流；DATA 最大 64 KiB、FIN 显式半关闭、RST 有界。写停滞最多 15 秒，dial/握手最长 10 秒。Agent 重连不能迁移或重放现存 SSH。
- 已通过真实 WS/yamux + SSH/SFTP 集成测试：Agent 路径下的主机探测、终端命令、文件下载、跨租约续期，以及撤销后会话关闭、录屏读取和离线拒绝。另有网段/端口/回环限制、租约目标绑定/重放/到期、帧半关闭测试。完整 Go、go vet、TypeScript 与前端构建通过。
