# r17-rc9 默认角色与 MyZone 共享盘

105 迁移在新安装及升级时创建缺失的“管理员”和“操作员”角色。同名角色不改名、不覆盖权限；已执行迁移后，重启不会恢复管理员主动删除或调整过的角色。不创建默认账号、不分配默认密码，不自动给现有用户分配角色。

- 管理员角色：预置迁移时权限目录中的全部功能权限。系统管理员账号类型仍独立决定 identity.manage 等身份管理能力；分配同名角色不等于把普通账号提升为系统管理员。
- 操作员角色：不预授予全局管理权限；普通账号使用“我的资产”等个人入口，连接权限由资源授权决定。需要额外模块权限时由管理员编辑角色。

共享盘显示名称由 NextTerminal 改为 MyZone，Windows 访问路径为 `\\tsclient\MyZone`。仅改变 RDP 驱动显示名称和页面提示，不改变用户存储、配额、ACL 或数据路径。更新 server 和 web 后，关闭并重新建立 RDP 会话生效；已有引用旧 UNC 名称的快捷方式需要更新。

验证：新初始化出现两个角色；管理员模板权限完整；操作员不能进入全局角色管理；再次执行迁移不覆盖权限调整、不创建重复角色；共享存储 ACL/配额、传统 RDP 会话回归通过。
