# Puppeteer r17-rc11

发布日期：2026-11-14。候选版本，linux/amd64。

- 数据库资产增加账号控制（默认）和程序控制。程序控制允许更宽目标账号权限及凭据复用；平台 SQL 策略、审批、审计和目标数据库自身授权继续生效。
- MySQL、PostgreSQL、SQL 工单及连接测试使用资产所选模式。已有资产保留账号控制，旧客户端省略字段更新时保留原模式。
- 测试连接按凭据类型提示权限错误；协议错误不再混用权限提示。
- 网关监听编辑时为空的 MySQL/PostgreSQL 地址预填容器内部地址，补充 Docker 映射端口与配置发布说明。
- 修复图形会话鼠标回调类型，恢复前端发布构建。

## 升级

后端包含 schema107 迁移，新增 permission_mode 并使原生 DML 凭据独立性约束按模式生效。升级前备份数据库；前后端应同时升级。模式修改后客户端需要重新连接。程序控制只约束经过平台的访问，目标账号直连不经过平台策略。

镜像及源码提交见 dockerhub-r17-rc11.json。安装脚本固定新镜像摘要；graphics、renderer 镜像沿用既有版本。本次发布不自动重启现有部署。

## 验证

生产前端类型检查、构建和产物清单校验通过；17 项前端专项测试通过。MySQL/PostgreSQL 真实夹具、模式保存与切换、旧客户端兼容、诊断和 SQL 策略专项回归通过。本次未重跑全仓端到端验收。
