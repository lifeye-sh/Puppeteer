# 后台导航分层

更新日期：2026-10-31。导航采用两层结构：数据概览独立展示，其余页面按工作场景归入七个分组。

| 一级入口 | 二级页面 |
| --- | --- |
| 数据概览 | 仪表盘 |
| 工作台 | 我的资产、我的数据库、我的 Web 资产、我的命令片段、我的申请、我的 SQL 工单、存储空间、通知偏好 |
| 资源管理 | 主机资产、数据库资产、Web 资产、授权凭据、证书管理 |
| 接入管理 | Agent 网关、SSH 跳板、网关组、网络代理、Web 接入设置、应用与原生接入 |
| 访问控制 | 资源授权、访问策略、动作策略、命令过滤、IP 集合、访问审批、SQL 工单审批 |
| 会话审计 | 在线会话、访问记录、命令记录、文件审计、数据库 SQL 审计 |
| 身份认证 | 用户管理、部门管理、角色权限、登录与身份源、登录锁定 |
| 系统运维 | 任务调度、系统命令片段、凭据轮换、Agent 监控、链路诊断、备份与恢复、通知配置、平台设置 |

## 入口边界

- 工作台面向个人使用；资源管理面向资产维护；接入管理集中管理网络通道及应用接入。
- 访问控制集中授权、策略与审批；会话审计集中会话和操作记录。
- 身份认证管理账号、组织和登录方式；系统运维管理任务、监控、备份和平台配置。
- 个人信息、个人访问凭据保留在右上角用户菜单，终端保留独立工作区。
- `/notification-preferences` 只展示个人通知偏好；管理员的 `/setting` 管理通知渠道等配置。普通用户访问旧 `/setting` 地址时跳转个人通知偏好。
- `/identity-settings` 集中登录策略、验证与恢复、OIDC / 企业微信及 LDAP 配置，取消原设置页中的多层嵌套。
- 备份与恢复统一使用 `/system-event`，不再嵌入通知或身份设置页。

## 导航行为与维护

- 同时只展开一个分组；直接访问页面或浏览器前进、后退时自动展开所属分组。
- 面包屑使用“首页 / 分组 / 页面”，菜单高亮与面包屑共用导航定义。
- 页面通过客户端路由切换，保持管理框架，不触发整页刷新。
- 保留原路由。数据库及 Web 资源授权旧入口归属“资源授权”。
- 按已有账号权限与后端能力过滤菜单，隐藏空分组；实际授权仍由页面路由和后端执行。
- 集中配置文件：`src/pages/backend/backend-navigation.ts`。新增页面时在对应分组配置路径、名称、权限和能力，同时维护 `src/App.tsx` 的路由保护。

验证命令：`node --experimental-strip-types --test tests/backend-navigation.test.mjs`、`npx tsc --noEmit`、`npx vite build --mode backend`。
