## 用户现在可以测试

1. 打开 <http://backend.localhost:5174>，用本机凭据文件中的 accept-admin 登录。本机已完成初始化，不需要再次创建管理员。
2. 先输入错误密码，确认页面显示错误；改为正确密码后进入“R01 验收工作台”。
3. 检查账号、实例 ID、数据库版本和功能开放状态。绿色“本轮可用”共 4 项。
4. 进入“我的账号”，核对只读信息，再返回首页。
5. 查看 3 项只读配置；点击“刷新审计”，核对刚才的失败/成功登录记录。
6. 点击“验证未开放页面提示”，确认资产页面不会误入旧后端，返回首页后仍保持登录。
7. 刷新浏览器，确认账号仍在；退出后重新登录，确认账号和审计保留。
8. 可选：按后端 README 重启 server，验证实例 ID 不变。访问 /setup 可检查“已完成初始化”状态；空库初始化已由真实浏览器自测覆盖，不清空当前验收数据。
