## 第一阶段：Telnet 与多协议会话基础

- 资产支持 SSH/Telnet；会话保存协议快照，资产/凭据变更、登录失效、管理员终止仍关闭连接。
- Telnet 走现有直连、Agent、SSH 跳板、网关组或网络代理拨号链；不回退直连。无 SSH 主机密钥探测，Telnet 不提供远端身份和传输加密。
- 有界 IAC 解析，ECHO/SGA/BINARY、终端类型和 NAWS 窗口尺寸协商；NVT 换行和 IAC 转义。未知选项拒绝，子协商最大 1024 字节。
- 原终端新标签页、只读输入控制、在线终止、输入提交识别和输出录屏复用；Telnet 禁用 SFTP 与独立 exec。登录在终端手工完成，不自动猜测提示符或注入凭据；关联凭据用于资产配置及版本失效检测。
- 归档证据只记录输出和可识别提交，免安装命令识别仍有局限，不宣称脚本内部命令可审计。Telnet 不回显输入使用原审计占位逻辑。

开发测试覆盖：真实 TCP/WebSocket Telnet 交互、无需 SSH 主机信任、只读输入不送达目标、管理员终止、录屏和提交审计；协议字节分片、IAC 转义、NVT 输入、尺寸协商和超长子协商拒绝。SSH 既有测试及 TypeScript/backend 构建已通过。

本地验收夹具：Compose telnet-fixture profile，无宿主端口。只提供 help/whoami/hostname/pwd/exit 固定诊断响应，绝不执行 OS 命令；验证协议链路，不能代替真实 Telnet 设备的登录兼容性验收。

## 第二阶段：RDP/VNC 图形连接及回放

- 增加 RDP/VNC 资产协议，默认端口 3389/5900。仅接受密码凭据，凭据在服务端审计解密后参与 guacd 握手，不进入浏览器、WebSocket URL 或录屏。
- RDP 使用 NLA，必填人工核验的证书指纹（FreeRDP `/cert:fingerprint` 格式），不启用 ignore-cert/自动首次信任。域账号可使用域限定用户名。真实 Windows 兼容性尚待实机验收。
- guacd 只部署在受信私网，不发布宿主端口。后端按资产既有路由拨号，单次临时中继只接受该 guacd 对端 IP；直连、Agent、跳板、网关组和代理继续由已有服务约束目标与授权。尚未实现跨不可信网络的 guacd 双向 TLS，不能把配置地址直接换成公网服务。
- 会话复用单次票据、Origin 检查、租约和周期授权检查。键鼠、尺寸操作由服务端执行只读控制；输入仅允许指定指令，最大帧 32 KiB。Guacamole 解析限制每条指令 256 KiB、256 个元素，校验 UTF-8 和分隔符。
- 本阶段关闭双向剪贴板、文件/磁盘映射、音视频、打印与对象通道，未提供放开这些通道的前端开关。
- 工作台保留左侧“我的资产”及会话标签，图形协议显示桌面；访问记录依据 `guacamole-events-v1` 使用图形播放器，支持播放、暂停、进度定位。播放只读且不会连接远端。
- 每条显示指令先持久化再转发；沿用 64 MiB 配额及归档完整性校验。审计写入失败关闭会话并标为 interrupted。

测试证据：`backend/.local/r07-graphics-test.log` 覆盖真实 TCP/WebSocket 与模拟 guacd：授权路由中继、键盘输入、只读键鼠/尺寸及剪贴板拒绝、管理员终止、图形录屏格式与配额失败关闭。`r07-graphics-regression.log` 全量 Go 测试及 go vet 通过；TypeScript 与 Vite backend 构建通过。当前 Alpine 测试镜像禁用 CGO，`-race` 未能执行，不能声明竞态检测已通过。

## 第三阶段：只读观察和指定用户分享

已部署 `r07.3-preview`。在线会话列表新增“只读观察”和“分享”，独立页面 `/session-observer?sessionId=...`；源会话所有者和管理员可以直接观察及管理分享。分享限定已启用且拥有该资产授权的指定用户名，不提供匿名分享或交互接管。

实现约束：

- 观察读取已经持久化的录屏前缀，从头同步已有画面后约每秒刷新；不创建 SSH、Telnet 或 guacd 控制连接，无键鼠/命令/尺寸/文件/剪贴板写入端口。图形使用 Guacamole 只读渲染，文本使用禁用输入的 xterm，并禁用 OSC 52 剪贴板写入。
- 分享令牌 256 位随机，仅保存摘要，最长 30 分钟、单次领取，绑定会话及接收用户；领取与观察租约创建同一事务提交。链接令牌位于 fragment，页面加载后从地址栏移除；接收者须先登录指定账号，再打开链接。
- 观察租约绑定账号与当前登录摘要。每次读取检查身份、角色/资产授权、分享撤销/期限及源会话状态；撤销或撤权后下一次读取拒绝，前端停止轮询并清空画面，原会话不受影响。
- 最多 8 个活跃观察者、每会话 256 次观察加入、64 次分享；观察最长 30 分钟，30 秒没有心跳即失效。前端退出主动释放名额，关闭浏览器时由闲置期限回收。领取后的分享无法再次加入，需重新生成链接。
- 每页最多 64 个已提交事件，读取上限固定为本页元数据的 total，避免并发录制时返回不一致的事件范围。浏览器观察上限 64 MiB / 20 万事件。源会话结束后展示最终已保存输出并停止；授权撤销不会继续返回新数据。
- 创建、领取、退出及撤销均记录审计事件，不记录原始分享令牌。

## r07.4：RDP 证书自动获取

- 新建或编辑 RDP 资产无需输入证书：指纹为空时，后端在保存前进行 X.224 安全协商及 TLS 握手，读取远端叶证书并保存 SHA-256 指纹。探测不发送登录凭据，不创建桌面会话。
- 表单提供“获取 / 更新远端证书”，显示主体、签发者和有效期。该按钮只预览，保存资产才持久化。地址、端口或连接路径变化后重新抓取；已有固定指纹不在连接时静默替换，guacd 仍使用 NLA 与证书校验。
- 支持资产配置的直连、Agent、SSH 跳板、网关组及网络代理。探测要求 identity.manage 权限，限制并发及频率，10 秒超时，成功抓取写入审计；探测失败不保存资产。
- API：POST `/api/admin/rdp/certificate` 接收资产草稿并返回 fingerprint、subject、issuer、notBefore、notAfter。普通资产保存支持自动抓取；JSON 批量导入沿用显式指纹契约。
- 验证：Go 全量测试通过（application 248.618 秒）及 go vet 通过，日志 `backend/.local/rdp-cert-regression.log`；覆盖实际 TLS 测试服务取证、自动保存、目标变化刷新、权限拒绝、不可达时不写入、非法协商及取消。TypeScript/Vite 构建通过，日志 `rdp-cert-ui-final.log`。
- 浏览器确认 RDP 表单指纹只读、无必填限制，自动取证按钮可见；部署 r07.4-preview，server/guacd 健康。TLS 测试服务不是 Windows 桌面，本次不据此宣称 Windows RDP 整体实机验收完成。

协议依据：[Microsoft RDP 安全协商](https://learn.microsoft.com/en-us/openspecs/windows_protocols/ms-rdpbcgr/902b090b-9cb3-4efc-92bf-ee13373371e3)。
