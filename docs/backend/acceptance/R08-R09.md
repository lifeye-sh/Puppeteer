## 接口与实施约束

所有管理写入需管理员权限；申请者、审核者与通知接收资格分别判断。修改类接口采用版本号，审批批准固定申请版本和内容，审批记录、grant、审计和通知意图共用事务。异步投递使用租约和幂等键；SMTP 等无幂等支持的服务存在“对端已接收而本端未确认”的重复风险，不把通知重试等同业务重做。

策略以服务器时钟和可信来源 IP 为准。先合并主体与资源事实，拒绝优先；配置地域约束但缺失地域数据时拒绝。动作授权独立于菜单。自由交互终端不能成为可靠的命令沙箱：绑定命令过滤时 SSH 只接受受审计的显式执行入口，禁止原始终端输入；不支持可靠强制过滤的协议必须明确拒绝该组合，不能静默放行。

用户已明确要求全部使用内网模拟环境。验收使用内网 SMTP 收件箱、企业微信 HTTPS 模拟接口、DNS/ACME 测试服务、测试 CA 和 HTTP/WebSocket 上游，并保留成功和失败场景证据；不将内网验收表述为公网生产渠道验收。
