# R16 网关监听与密码安全（schema102）

入口：平台设置 → 登录安全、网关监听、配置发布。schema101 增加 HTTP、网站 TLS 与原生 RDP 的统一监听管理；schema102 增加经管理员复核的验证码配置。实际部署版本以运行状态页为准。

## 密码与 MFA

- 推荐策略：至少12个Unicode字符、禁止包含账号、检查内置常见弱密码及全重复字符；允许长口令，不强制多字符类别。自定义策略严格解析五字段JSON；界面提供数字和开关控件，8–128字符、字母/数字/其他共1–3类，可限制回文。内置弱密码列表不是外部泄漏密码数据库。
- 本地密码有效期默认-1（不限）；1–3650天，0拒绝。schema75之前的密码从迁移时开始计时，不伪造历史修改时间。到期后的本地密码登录或旧浏览器会话转入5分钟改密阶段；业务接口与MFA绑定接口不可用。外部身份提供方独立管理密码期限。
- 个人中心可主动改密；需要原密码及已绑定TOTP的新时间步。改密撤销旧登录、原生授权、个人Passkey/API Key/SSH公钥和个人数据库密码，保留MFA绑定；资产凭据不修改。
- 全局强制TOTP默认关闭。开启后，无已验证MFA时间戳的浏览器会话转入绑定或验证阶段；MFA完成时间持久化，之后不重复要求绑定。原生SSH公钥准入与续租也执行要求。个人API Key的非交互访问不使用此浏览器登录开关。

## 监听与证书

SSH、MySQL、PostgreSQL分别有监听开关和地址。开关迁移默认true、地址空，保持已有部署行为；若环境变量也未指定地址，则不启动对应监听。显式地址只接受IP与1–65535端口，例如`0.0.0.0:2022`、`127.0.0.1:13306`、`[::]:15432`。

1. 配置以新修订提交，节点先绑定全部新端口并验证证书，准备完成才切换接入。
2. 端口冲突、证书无私钥/过期/吊销/主机名不符等导致failed，保留旧监听和已建立连接；失败版本暂停新连接，管理员修复后显式重试或提交补偿修订。
3. 成功切换后关闭旧监听socket；旧连接保留原处理器和证书，按原会话规则自然结束。关闭监听停止新接入，不主动踢出既有连接；应用停机、维护与恢复隔离仍会终止连接。
4. 数据库代理证书留空使用平台自动生成证书；也可选择平台服务器证书，必须匹配部署的数据库代理公开主机名。证书轮换不重绑相同端口，新连接使用新证书；客户端下载接口只发布已切换的证书。
5. 客户端入口与状态接口使用成功切换后的地址，而不是准备失败的目标地址。Docker端口映射、公开名称与防火墙仍由部署管理；界面不擅自开放宿主机端口。

schema101 起统一管理 SSH、MySQL、PostgreSQL、HTTP 管理入口、网站 TLS 和原生 RDP 监听。HTTP 管理入口始终保留，不能关闭；启动时先使用部署地址，成功应用配置后再切换。维护与隔离恢复只保留管理入口，便于诊断和恢复。更改管理端口前须准备反向代理、容器映射及访问新地址的方式。

### HTTP、网站 TLS 与原生 RDP

- `http-server-addr`、`website-server-addr`、`native-rdp-addr` 为空时继承部署地址。网站和 RDP 的 enabled 默认为 true，但部署没有提供相应服务时不会凭空启动。公开 RDP 地址由 `native-rdp-public-address` 或部署值提供；只有成功发布后才更新客户端入口。
- HTTP 与网站监听在独立管理器中准备；其他协议准备失败时撤销未提交端口，管理入口继续可用。HTTP keep-alive 和 WebSocket 升级连接在切换后保持，应用停机才关闭。
- 网站 TLS 按 SNI 动态选择平台证书。失败修订下，新网站连接被拒绝；管理接口保留，以便修正配置或重试。
- 原生 RDP 仅在 Linux 且已配置 worker、FFmpeg、证书和密钥时启动。准备阶段检查绝对路径、可执行文件、证书有效期及公开地址 SAN。默认只绑定 loopback；明确的部署容器 profile 才允许容器监听地址。
- RDP 每代监听保存已验证的证书快照；路径内容变化不会让旧连接读取到半更新证书。跨代共用两个 worker 槽位，切换不会扩大发起能力。更改证书文件后需发布新修订才能应用。
- 管理端口冲突、其他协议准备失败、重试、冻结恢复、证书失效/主机名不符以及旧升级连接保留均有测试；真实 FreeRDP 客户端经过受管监听完成图像和录屏验证。页面保存冲突版本后可修正并恢复 effective。

## 登录验证码（schema102）

`login-captcha-enabled` 默认 true。改变配置需要管理员当前密码及已绑定的全新 MFA 口令，并记录配置审计。关闭等待在线节点 ACK；开启立即收紧。配置读取异常拒绝放行，隔离恢复强制开启。

适用于新发起的密码、LDAP、OIDC/企业微信、Passkey 和短信认证。变更清除尚未使用的登录拼图和证明；已登录会话不退出，已经开始的外部授权或动态码流程沿原有效期结束。限流、账户锁定、密码和 MFA 要求仍独立执行。开关验收只能在隔离环境进行，业务环境保持开启。

## 验收边界

- 独立子进程各有自己的连接池，经真实TCP代理访问隔离PostgreSQL。断开已有连接并拒绝新连接，验证失联消费者拒绝缓存准入、缺ACK不报全部effective、重连追上最新版本、杀进程后同身份重启读取最新版本、全部进程数据库网络失联后恢复。
- 上述矩阵验证配置消费与发布反馈；schema79/80已补跨节点安全策略放宽屏障；仍没有替代所有业务租约的完整故障验收。
- 实际SSH握手、端口冲突/失败锁存/重试/切换/旧连接保留；PostgreSQL SSLRequest及verify-full TLS握手、同端口证书轮换、错误主机名拒绝均已通过隔离测试。
- 页面验证不得在业务实例开启全局MFA、缩短密码期限或修改生产监听进行试验；变更场景使用隔离测试实例。

## SSH 主机身份（schema81）

平台设置 → 网关监听 → SSH主机身份，支持单段未加密OpenSSH/PEM Ed25519、ECDSA或RSA≥2048私钥。输入空串或掩码保持；明确清除恢复原平台自动生成密钥。替换/清除要求管理员密码和已绑定TOTP，实际主机公钥仅在监听成功提交后切换。旧连接保留。隔离恢复清除自定义引用，重新生成独立主机身份。
