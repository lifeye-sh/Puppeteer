## 已交付功能

- 数据库资产 CRUD、独立只读/工单执行凭据、版本冲突保护、资源授权和门户脱敏列表。管理员“测试连接”分别校验目标 TLS、凭据、权限并执行 SELECT 1。
- 个人数据库密码创建、重置、撤销及过期校验；二次身份验证、Vault 加密 Argon2id 验证材料、有限认证并发；隔离恢复丢弃旧密码。
- MySQL TLS 代理、caching_sha2_password full authentication、username@asset_alias 身份映射。目标 TLS 独立验证 CA 和服务器名称，目标权限检查与 SESSION TRANSACTION READ ONLY 双重限制。
- 普通查询、预编译参数、长参数、事务、元数据查询与逐命令审计。权限/用户/密码变更终止连接；绑定参数只记录类型、长度与空值状态。
- SQL 工单提交、非本人审批/拒绝、取消、执行与结果分页。冻结资产/凭据版本和 SQL 摘要；DML 事务与 DDL 分离；执行前及 COMMIT 前重新授权。
- 执行结果与 SQL 审计、通知 outbox 关联执行 ID。提交结果无法确定、回滚警告、失联 Worker 使用 unknown，不自动重试；DDL 部分成功保留各步骤结果。
- 隔离恢复关闭旧连接、禁用资产、取消待执行任务，将不确定的在途任务及审计标记为 unknown。

## 范围与限制

- 当前 MySQL 8.4 基线；PostgreSQL 原生代理属于后续扩展，内部 PostgreSQL 业务库不代表 PG 代理已交付。
- 代理与目标数据库均需 TLS 验证；原生客户端必须能解析代理证书对应的主机名。backend.localhost 的浏览器解析行为不能代替原生客户端 DNS 配置。
- 普通 SQL 文本进入审计；仅预编译绑定值不落库，不承诺所有普通 SQL 字面量脱敏。
- SQL 最大 1 MiB；工单最多 100 条；结果最多 1000 行，另有字节预算；长参数每连接最多 64 MiB，容器专用 tmpfs 总上限 128 MiB。
- 未进行生产容量压测，不宣称兼容全部客户端或全部 MySQL 指令。保留 fail-closed 的不支持指令策略。
- 前端入口：数据库资产、我的数据库资产、数据库授权、SQL 工单、我的 SQL 工单、SQL 审计、我的账号。
