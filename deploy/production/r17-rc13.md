# Puppeteer r17-rc13

日期：2026-11-15。Linux amd64；schema 110，能力版本 90。

本版本承接 [rc12 源码交付](r17-rc12.md)，发布配套 server、web、graphics 和 renderer 镜像，以及匹配的一键安装与升级流程。最终镜像摘要与构建源码提交记录在 dockerhub-r17-rc13.json。

网页内 RDP 使用 guacd，不需要原生 RDP Worker。Linux 一键安装完成后自动接入部署执行器；现有安装升级保留数据卷、密钥与组件停用状态。升级需要维护窗口，先备份配置、数据库和应用文件。脚本不修改防火墙或云安全组。

升级跨越 schema 110 后不能直接切回 rc11 镜像。发生失败时保留备份和诊断文件，按升级说明恢复。
