## 首批交付（历史记录）

- 数据库资产新增 `engine=mysql|postgresql`。历史数据和旧客户端新建默认 MySQL；旧客户端编辑省略 engine 时保留原类型。类型创建后不可切换，避免连接/工单改走另一协议。编辑保留版本冲突和授权隔离。
- PostgreSQL 使用独立 pgx 连接边界，TLS1.2+、指定 CA 和服务器名称校验、强制 SCRAM-SHA-256，无明文回退、无本地 Unix socket、清除环境运行参数。按资产连接超时完成连接、权限校验及 SELECT 1；目标错误仅显示分类信息，不回显凭据。
- 只读诊断检查有效权限（含 PUBLIC、列级授权和角色成员关系）：拒绝管理角色、继承角色、数据库/对象所有权、CREATE/TEMP、表写入、序列修改、可访问外部表及非系统函数执行；额外设置默认只读事务。仅通过 SELECT 1 不等于权限安全。
- 新生成/重置的个人数据库密码，在原有有界验证池内一次生成 Argon2id 与 SCRAM 服务端验证材料。SCRAM salt16字节、iterations32768、StoredKey/ServerKey32字节；两者作为版本化 bundle 由 Vault 加密并绑定用户，不保存明文密码。真实 PostgreSQL18 已验证该材料兼容 SCRAM 登录。
- 原 Argon2id 密码继续用于 MySQL，无法逆推出 SCRAM，状态接口返回 `scramReady=false`；后续使用 PG 时用户自行重置。吊销清除两种验证材料并使状态不可用，隔离恢复仍清除个人数据库密码。

## 原生只读预览交付（2026-11-11）

- 监听与 MySQL 独立，强制 TLS1.2+、SCRAM-SHA-256，目标密码不发送到客户端。旧 Argon2-only 密码继续用于 MySQL；PG 必须由用户本人重置以生成 SCRAM 材料。本次未重置现有管理员个人密码。
- 支持 simple query、Parse/Bind/Describe/Execute、具名/匿名 statement 与 portal、分页暂停/继续、pipeline、Flush/Sync 和取消。策略拒绝也使上游事务进入失败状态；错误后忽略扩展消息直到 Sync，事务由 ROLLBACK 恢复。
- 每条命令前与5秒租约校验用户、授权、密码版本、资产版本/状态、凭据版本及会话状态；撤销会关闭忙碌和空闲连接。随机取消 PID/key 绑定来源地址，关闭后删除映射，不公开目标数据库取消密钥。
- SQL 通过 PostgreSQL AST 只读允许列表；同时检查目标最小权限及默认只读事务。解析器实际 AST 版本170007，未覆盖的新语法按拒绝处理，不能宣称支持 PG18 全部语法。允许 SELECT/SHOW、有限 SET、无选项事务控制、COPY TO STDOUT；拒绝 DML、SELECT INTO、锁定查询、COPY FROM/PROGRAM/文件以及不在允许列表的函数、类型和操作符。
- 64连接上限；客户端帧1MiB、目标帧8MiB、单次响应64MiB、普通结果单次100000行；目标 statement_timeout10秒、lock_timeout3秒。statement/portal 各256、SQL缓存4MiB、绑定参数最多1024。COPY 行数从 CommandComplete 统计，COPY流受字节限制。
- 审计 Q/P/E 命令、SQL摘要/文本、返回行数、耗时和结果。绑定参数只记录 OID、格式、长度和 NULL，不记录值；Describe 推断类型同步到审计。连接断开且未确定结果时由会话收尾标记 unknown。SQL文字中的字面量仍按原有 SQL 审计保存。
- 状态接口新增 `postgres` 子对象，保留 MySQL 原字段；证书下载两种协议共用（保留旧文件名）。前端增加 PG 连接说明、预览边界、PG 命令名与 OID/编码展示。
