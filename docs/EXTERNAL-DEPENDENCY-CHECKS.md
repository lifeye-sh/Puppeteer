# 外部依赖统一预检（P1-2）

已接入「平台配置 → 外部依赖」及各资源详情：邮件/通知、LDAP、OIDC/企业微信、Passkey、AI、备份复制、ACME、OIDC 服务端/原生客户端、SSH 转发、MySQL 原生 DML，以及 Agent 网关、跳板、网关组和网络代理。

## 操作与证据

保存配置后点击「依赖预检」。任务持久化并逐项展示进度、失败原因和修复建议，可刷新或取消只读预检。检查针对已保存配置、当前节点、资源版本和操作者；证据有效期五分钟。配置、资源、引用或相关凭据变化使旧结果失效；状态请求失败也显示过期，不能继续显示绿色成功。

预检只证明列出的阶段，不统一替代各功能已有的保存校验、启用保护或业务授权。开关开启仍不代表业务可用；服务端实际调用继续检查权限。状态页保留「期望 → 应用 → 依赖 → 实际业务」四维展示。

| 功能 | 自动预检范围 | 仍需实际业务验证 |
| --- | --- | --- |
| SMTP / 通知 | DNS/TCP、TLS/CA、SMTP 认证；企业微信令牌、Webhook TLS；规则及绑定情况 | 显式测试投递、接收人实际收取；预检不发送邮件或通知 |
| LDAP | TLS、服务账号绑定、Base DN、有限查询及身份属性映射 | 用户登录、同步任务；不导入用户 |
| OIDC / 企业微信 | 发现文档、应用凭据和配置 | 授权、回调及真实身份映射；不修改外部平台后台 |
| Passkey | HTTPS 来源、RP ID、部署白名单；页面另查浏览器基础支持 | 实际设备注册及认证 |
| AI | 真实出站策略和代理、TCP/TLS、模型配置、密钥存在、许可及当前操作者预算 | 明确调用测试；预检不发送 API Key、不调用模型、不产生模型用量 |
| 备份复制 | S3/SFTP/WebDAV 连接、身份、证书/指纹及目标路径 | 显式点击「读写、摘要与清理验证」 |
| ACME | 账号密钥、HTTPS 目录、TSIG 签名 DNS 查询、待清理挑战 | 订单签发、TXT 更新及清理；预检不注册账号、写 DNS 或申请证书 |
| OIDC 服务端 / 原生客户端 | 已有签名及 HMAC 密钥、固定 Issuer、HTTPS 发现/JWKS、客户端登记、用户许可和实际协议入口 | 逐用户和资产授权后的完整会话 |
| SSH 转发 / 原生 DML | 网关、精确固定目标、实际连接凭据和策略；关闭后核验相关记录结束 | 不新增公开端口、不写 SQL；事务未知结果仍需目标端核验 |
| Agent / 跳板 / 网关组 / 网络代理 | 已登记引用的实际连接路线、凭据、目标 TCP/TLS，不静默回退直连 | 远程安装沿用安装任务，启用资源不会自动安装软件 |

## 备份读写验证与清理

显式验证创建隔离加密测试文件，执行写入、摘要回读及删除，不修改现有备份。写入前持久化加密目的地快照和清理信息并复核权限。同一目的地存在未清理验证时不继续写入。此阶段不可取消，确保清理继续执行；失败原因显示在任务中。

服务进程中断后后台恢复清理，清理失败保留记录并重试。恢复应用备份时移除源实例测试清理记录，避免恢复实例删除源实例对象。目标连接配置及凭据不会出现在任务文本中。

## API、安装和兼容

新增迁移 `109_dependency_probe_artifacts.sql`，保留迁移 108 的统一任务表；能力版本 89。无需新增容器、端口或手工迁移。

资源级状态：`GET /api/settings/operations/{资源类型}:{UUID}`；提交预检使用同路径 `/preflight`，同时携带当前 `If-Match: "settings-版本"` 和响应的 `evidence`。备份显式验证使用 `/verify`。一般要求管理员及 `identity.manage`，备份操作另要求 `backup.manage`；资源查看沿用对应权限。取消仅限只读任务。

旧服务端不支持时显示能力不足；既有 LDAP、OIDC 授权和管理员防锁死保护保留。安装/升级按既有流程备份并同步前后端，不能只更新页面。

应用备份的显式兼容版本同步到 schema 109；恢复隔离会使源预检证据过期并移除源测试清理记录。备份/恢复支持范围见 [备份与隔离恢复](backend/implementation/backup-restore.md)。
